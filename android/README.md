# 밤과 아침 — 안드로이드

이 디렉터리는 안드로이드 앱 소스입니다. 현재 미리보기 환경에서는 APK를 빌드하지 않았으며 아래 네이티브 동작은 **실기기 검증 전**입니다. 웹 미리보기는 알람, 예약 상태, 사용량 권한을 대신 흉내 내지 않습니다.

## 기기에서 실행하기

1. 프로젝트 루트에서 Node.js 22 이상을 사용해 `npm ci`를 실행합니다.
2. JDK 17, Android SDK 35와 Gradle 8.11.1을 사용하는 Android Studio에서 `android` 폴더를 열어 동기화합니다. 디버그 기기를 선택하고 `app`을 실행합니다. CLI에서는 `gradle -p android :app:assembleDebug`로 빌드할 수 있습니다. 저장소에는 Gradle 실행 파일이나 SDK를 포함하지 않습니다.
3. 안드로이드 9 이상을 대상으로 합니다. 최소 안드로이드 14 이상의 실제 기기에서 권한·예약을 확인하고, 가능하면 안드로이드 12 또는 13에서도 반복합니다.

공통 화면은 APK에 묶여 네트워크 연결 없이 실행됩니다. 사용자 기록은 앱 안의 로컬 저장소에만, 알림 일정과 예약·발송 요청·알림 열기 시각은 별도의 기기 내 저장소에 남습니다. 예약이나 발송 요청으로 알림을 실제로 보고 들었는지는 판단하지 않습니다. 사용 정보 권한을 선택하면 앱 이름·이용 내용을 남기지 않고 구간 내 화면 활성·다른 앱 전면 전환 신호의 유무만 남깁니다. 짧게 이어서 누르는 등 수집 조건이 맞지 않거나 권한이 없으면 미수집으로 남깁니다.

## 실기기 확인

| 상황 | 확인할 결과 |
| --- | --- |
| 기상 알람 권한만 거부 | 기상 알람이 ‘예약되지 않음’. 알림 권한을 허용했다면 체크리스트 알림은 별도로 예약될 수 있음. |
| 알림 권한 또는 해당 채널 거부 | 해당 예약이 없는 것으로 표시. 홈에서 두 체크리스트와 기록 시각 직접 입력 가능. |
| 잠금 또는 백그라운드, 앱을 최근 목록에서 제거 | 기상 알람과 체크리스트 알림이 서로 다른 제목과 채널로 도착. 기상 알람 끄기나 알림 열기로는 기상 시각이 생기지 않고, ‘일어났어요’만 기록. |
| 예약 후 평소 기상 시각·당일 예정 취침 시각 변경 | 기존 예약 취소, 변경된 시각에만 발송. 불규칙 일정 질문을 무응답 또는 건너뛰면 수면 전 알림 없음. |
| 전후 체크리스트 미완료 후 기다리기 | 설정 간격에 따라 단계별로 최대 한 번 재알림. 완료·건너뛰기 또는 수면 전 ‘이제 잠을 청할게요’ 이후에는 해당 재알림 없음. |
| 알림에서 열기 | 일정 질문은 해당 밤 일정 입력, 체크리스트는 해당 밤 설문, 기상 알람은 해당 밤 홈을 엶. |
| 다시 시작 후 첫 잠금 해제, 시간대 변경 | 저장한 미래 예약을 복원. 현재 시간대에서 설정한 시각을 확인. |
| 사용 감지 조건별 비교 | 권한 거부 또는 기능 끔은 미수집. 권한 허용 후 두 버튼 사이 화면을 켜 다른 앱을 쓰거나, 화면을 켜지 않고 각각 비교. 결과를 입면 또는 각성으로 표시하지 않음. |

체크리스트 알림은 정확한 알람 권한이 없으면 지연될 수 있습니다. 전원 관리, 알람 채널 소리·기기 음량, 방해 금지 설정은 실제 발송 및 소리에 영향을 줍니다. 강제 종료 후에는 앱을 다시 열어 예약을 갱신해야 합니다. 미래 예약은 앱을 열거나 설정을 바꿀 때 최대 14일 앞까지 채우므로 14일 이상 열지 않으면 이후 일정은 예약되지 않습니다. 강제 종료·전원 관리에 대한 우회는 적용하지 않습니다.
